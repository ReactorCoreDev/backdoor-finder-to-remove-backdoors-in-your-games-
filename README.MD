  <h3>Macros</h3>
  <p>Macros are strings that get replaced so you don't have to type out your information each time.</p>

  <table border="1" align="center">
    <tr>
      <th>MACRO</th>
      <th>INFO</th>
    </tr>
    <tr>
      <td>%username%</td>
      <td>Your username</td>
    </tr>
    <tr>
      <td>%userid%</td>
      <td>Your User ID</td>
    </tr>
    <tr>
      <td>%userping%</td>
      <td>Your ping</td>
    </tr>
    <tr>
      <td>%debug%</td>
      <td>Your debug setting</td>
    </tr>
  </table>

  <h4>Example macro usage:</h4>
  ```lua
  print(%username%)
  ```
